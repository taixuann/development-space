# Impeccable: UI & Frontend Craft Floor

Enforce visual and structural excellence for any user interface in this workshop:

1. **Information Architecture**: Clean hierarchy, consistent spacing, and readable typography before decorations.
2. **Design Tokens**: Standardize colors, font weights, and border radii.
3. **Responsive & Accessible**: Support dynamic screen widths, high contrast, and keyboard navigation.
4. **Verification**: Always inspect rendered outputs or run headless UI checks (Playwright) on UI changes.
