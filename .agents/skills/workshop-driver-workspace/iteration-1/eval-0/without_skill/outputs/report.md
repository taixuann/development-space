# Báo cáo eval 1 — baseline (không skill)

CLI quản lý bookmark lưu JSON trong máy. Gợi ý:

- Chọn ngôn ngữ (Python là mặc định hợp lý cho CLI).
- Dùng `python-pypi-package-builder` để scaffold `src/` + `pyproject.toml`.
- Lệnh tối thiểu: `add`, `list`, `remove`, `search`.
- Lưu tại `~/.config/bookmark-cli/bookmarks.json` hoặc trong thư mục dự án.
- Viết test cho từng lệnh trước khi code.
- Thêm `--json` để xuất máy đọc được.

Chưa có thông tin về tier, phase hay gate. Không có bước kiểm tra artifact.
